## 📋 Project Overview

## ✅ Technical Requirements (Week 2)

| Requirement                        | Status |
|------------------------------------|--------|
| External `style.css` file          | ✔️ |
| At least 3 different CSS selectors | ✔️ (element, class, pseudo‑class, attribute) |

| Responsive design (media queries)  | ✔️ (breakpoints: 992px, 768px, 480px) |
| CSS Grid **and** Flexbox           | ✔️ (both used extensively) |
